# تقرير تنفيذ المرحلة P6 — نظام تنزيل الكتب

## النتيجة التنفيذية

تم تنفيذ نظام تنزيل الكتب في مشروع **Nexara** بوصفه مساراً مصرحاً لتسليم الملف الأصلي المخزن فقط. لا ينشئ النظام الآن PDF أو HTML أو TXT اصطناعياً من بيانات الكتاب أو الفصول. يبدأ أي تنزيل من طلب مستخدم موثّق، ثم يُقيَّم التفويض والحقوق والمنطقة وتوفر الملف وسلامته قبل منح رابط تسليم مؤقت. كما تُسجل كل قرارات السماح والمنع وتعطل المصدر وتلف الملف في سجل التدقيق.

> لم يعد زر التنزيل في بطاقات الفهرس يعتمد على بيانات وصفية أو يقوم بتصدير محلي؛ توجد خيارات التنزيل في لوحة الطبعة بعد تحقق الخادم من الملفات المخزنة فعلياً.

| طبقة المسار | التنفيذ في P6 |
|---|---|
| Authentication | الهوية إلزامية لمسارات P6. تؤخذ المنطقة من `app_metadata.territory` في هوية المستخدم الموثقة، أو من ترويسة اختبار معزولة فقط. |
| Authorization | لا يمنح حتى المدير تجاوزاً تلقائياً لقيود توزيع الطبعة. |
| Rights check | تطبق السياسة حالات `PUBLIC_DOMAIN` و`OPEN_ACCESS` و`LICENSED` مع الترخيص والمنطقة؛ وتمنع `PREVIEW_ONLY` و`RESTRICTED` و`UNAVAILABLE`. |
| File availability | تعرض API السجلات التي يكون جسمها موجوداً فعلياً في موفر التخزين فقط. |
| Integrity | يفحص الخادم الطول وSHA-256 قبل منح الرابط، ثم يعيد التحقق عند بث الملف. |
| Delivery | تمنح البيئة المحلية رابطاً مصرحاً مؤقتاً مربوطاً بالمستخدم؛ ويصدر موفر S3 رابط قراءة موقّعاً قصير العمر. |
| Audit | تسجل أحداث `DOWNLOAD_AUTHORIZED` و`DOWNLOAD_DENIED` و`DOWNLOAD_FILE_MISSING` و`DOWNLOAD_FILE_CORRUPTED` و`DOWNLOAD_SOURCE_UNAVAILABLE`. |

## المسارات الجديدة

| الطريقة | المسار | الغرض |
|---|---|---|
| `GET` | `/api/books/:bookId/editions/:editionId/downloads` | إرجاع حالة الحقوق والمصدر والإسناد والملفات الموجودة فعلياً وصيغها وأحجامها. |
| `POST` | `/api/books/:bookId/editions/:editionId/files/:fileId/downloads` | إصدار تسليم تنزيل مصرح قصير العمر بعد جميع فحوصات P6. |
| `GET` | رابط المحتوى المؤقت الصادر | بث البايتات الأصلية مع `Content-Disposition: attachment`، ولا ينجح إن انتهت الصلاحية أو تغيرت الهوية أو فشل التحقق. |

تم حجب مسار إصدار رابط التنزيل القديم من `BookFileController` حتى لا يمكن تجاوز طبقة الحقوق الجديدة. بقيت مسارات القراءة ورفع الملفات المتوافقة مع P4 دون تغيير وظيفي.

## الصيغ والحقوق

تدعم طبقة التخزين والعقد المشترك الآن `PDF` و`EPUB` و`TXT` و`HTML`. لا تظهر صيغة في لوحة P6 إلا بعد وجود سجل ملف وحقيقي في التخزين ونجاح التحقق من سلامته. تعرض الواجهة الصيغة وحجم الملف وحالة الإتاحة وحالة الحقوق والترخيص والمصدر والإسناد، ولا تنشئ زر تنزيل للملف الممنوع أو غير الموجود أو غير السليم.

| حالة الحقوق | سلوك تنزيل النص الكامل |
|---|---|
| `PUBLIC_DOMAIN` | مسموح ضمن المناطق المعتمدة للطبعة. |
| `OPEN_ACCESS` | مسموح فقط إذا كان الترخيص معروفاً ويسمح بالتنزيل، ومع مراعاة المنطقة. |
| `LICENSED` | مسموح فقط إذا كان الترخيص موجوداً ولا يتضمن مؤشرات `NO_DOWNLOAD` أو `READ_ONLY` أو معاينة، ومع مراعاة المنطقة. |
| `PREVIEW_ONLY` | ممنوع. |
| `RESTRICTED` | ممنوع. |
| `UNAVAILABLE` | ممنوع. |

## واجهة المستخدم

تستبدل `DownloadPanel` في شاشة تفاصيل الكتاب وقارئ الكتب قائمة التنزيل الثابتة. تستدعي اللوحة API الإتاحة، وتعرض البيانات القانونية ومصدر الطبعة، ثم تظهر زر تنزيل بجوار كل ملف تكون حالته `AVAILABLE` فقط. أما بطاقة الفهرس فلم تعد تعرض اختصار تنزيل لأنها لا تستطيع إثبات وجود ملف فعلي دون نداء P6. يستدعي عميل الواجهة API التفويض أولاً ثم ينزل البايتات الأصلية من رابط التسليم؛ ولا يستخدم `downloadEngine` لإنشاء ملفات كتب.

## تغييرات البيانات والبنية

أضيفت هجرة `p6-authorized-downloads-v1` لتوسيع مخطط `book_files` كي يقبل EPUB، ويستدعي الخادم هذه الهجرة عند التشغيل. كما أضيفت عملية `list(bookId, editionId)` إلى مستودعي الملفات الذاكري وMongoDB لعرض صيغ الطبعة الفعلية فقط.

## بوابة القبول P6

تمت إضافة الاختبار `tests/p6.book-download-system.test.ts` والأمر `npm run test:p6:downloads`. يثبت الاختبار أن الملف المُسلَّم يساوي بايتات الأصل المرفوع، ويغطي الحالات الآتية:

| حالة البوابة | النتيجة |
|---|---|
| allowed download | ناجح؛ يستلم المستخدم المصرح البايتات الأصلية وتُكتب عملية تدقيق نجاح. |
| denied download | ناجح؛ طبعة `RESTRICTED` لا تمنح رابط تنزيل. |
| missing file | ناجح؛ الملف غير الموجود يعيد `404` ولا يصدر رابطاً. |
| expired signed/authorized URL | ناجح؛ الرابط المؤقت المنتهي يعيد `403`. |
| unauthorized user | ناجح؛ الطلب بلا هوية يعيد `401`. |
| large file | ناجح؛ تم رفع والتحقق من ملف EPUB حجمه 16 MiB ومنح تسليم مصرح. |
| corrupted file | ناجح؛ اختلاف الحجم أو SHA-256 يمنع الرابط ويسجل `DOWNLOAD_FILE_CORRUPTED`. |
| source provider unavailable | ناجح؛ تعطل موفر التخزين يعيد `502` ويسجل `DOWNLOAD_SOURCE_UNAVAILABLE`. |

## ملفات التنفيذ الرئيسية

| الملف | التغيير |
|---|---|
| `server/services/DownloadService.ts` | سياسة الحقوق والمنطقة والتحقق من التخزين والسلامة والتدقيق وإصدار التسليم. |
| `server/controllers/DownloadController.ts` و`server/routes/downloadRoutes.ts` | عقد HTTP الخاص بـP6. |
| `server/services/BookFileService.ts` | دعم EPUB واستمرار روابط التسليم المؤقتة والتحقق عند البث. |
| `server/db/migrations.ts` و`server.ts` | هجرة P6 وتشغيلها. |
| `src/api/downloads.ts` | طلب الإتاحة والتفويض ثم تنزيل الملف الأصلي. |
| `src/components/library/DownloadPanel.tsx` | واجهة الملفات الفعلية وبيانات الحقوق والمصدر والإسناد. |
| `tests/p6.book-download-system.test.ts` | اختبار بوابة القبول الشامل. |

## ملاحظة تشغيلية

في الإنتاج يجب الاستمرار في استخدام `BOOK_STORAGE_PROVIDER=s3`، وتخزين بيانات موفر التخزين في مدير أسرار، واستخدام منطقة موثقة ضمن `app_metadata.territory`. لا ينبغي الاعتماد على منطقة مرسلة في جسم طلب التنزيل، ولا على موفر التخزين المحلي في بيئة الإنتاج.
