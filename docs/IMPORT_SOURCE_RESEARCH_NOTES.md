# ملاحظات بحث مصادر الاستيراد

## Arabic Collections Online (ACO)

- الصفحة الرئيسية الرسمية لـ ACO تصف المجموعة بأنها مكتبة رقمية عامة لمحتوى عربي في الملكية العامة، وتعرض 17,698 مجلداً و10,474 موضوعاً في وقت التحقق.
- صفحة NYU Abu Dhabi الرسمية تصرح بأن المستخدمين يقرأون العناوين عبر الإنترنت أو ينزّلونها بصيغة PDF منخفضة أو عالية الدقة، وأن لكل عنوان رابطاً دائماً.
- عنوان مثال موثق من صفحة NYU: `https://aco.dlib.nyu.edu/book/columbia_aco001050/1`.
- محاولة فحص HTML للعنوان من المتصفح انتهت باتصال مغلق من الموقع؛ لذلك لن يستخدم التنفيذ أي رابط تنزيل مُخمّن. تتطلب بوابة ACO رابط PDF صريحاً من صفحة عنوان ACO نفسها أو مدخلاً أدخله المدير ضمن نطاق ACO المسموح، ثم تتحقق من ملف PDF وبصمته قبل الحفظ.
